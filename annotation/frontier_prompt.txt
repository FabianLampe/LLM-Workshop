# AUFGABE

Du bist ein präziser Daten-Annotator für deutsche Stellenanzeigen. Extrahiere aus jeder Anzeige strukturierte Informationen nach dem unten definierten Schema.

ANTWORTE AUSSCHLIESSLICH mit einem gültigen JSON-Array (eine Zeile pro Anzeige), KEIN Begleittext, KEINE Markdown-Codefences, KEINE Erklärungen.

# SCHEMA

Jede Anzeige bekommt ein JSON-Objekt mit genau diesen 7 Feldern:

- `id` (string): die refnr der Anzeige (so wie unten angegeben)
- `homeoffice` (string): einer von "ja" | "teilweise" | "nein" | "remote" | "nicht_genannt"
- `vertragsart` (string): einer von "ausbildung" | "festanstellung" | "praktikum" | "werkstudent" | "sonstiges"
- `erfahrungslevel` (string): einer von "junior" | "mid" | "senior" | "egal" | "nicht_genannt"
- `gehalt_min_eur` (integer ODER null): Untergrenze als ganze Zahl ohne Tausender-Trennung. null wenn nicht genannt.
- `gehalt_zeitraum` (string ODER null): "monat" | "jahr" | null. MUSS null sein, wenn gehalt_min_eur null ist.
- `skills_top3` (Array von max. 3 strings): nur konkrete technische Tools/Sprachen/Frameworks. KEINE Soft Skills, Sprachen, Schulfächer. Leeres Array, wenn keine technischen Skills genannt.

# WICHTIGE REGELN

**homeoffice:**
- "remote" NUR bei "100% Home Office", "Vollzeit Remote", "ortsunabhängig"
- "teilweise" bei "hybrid", "X Tage Homeoffice", "mobiles Arbeiten", "Gleitzeit und Homeoffice"
- "ja" wenn "Homeoffice" / "Home Office" steht OHNE Modalität
- "nein" bei "Präsenzpflicht", "vor Ort zwingend"
- "nicht_genannt" NUR wenn Anzeige NICHTS dazu sagt — nicht als Sicherheits-Antwort bei Unsicherheit

**vertragsart:**
- "Ausbildung" / "Azubi" → ausbildung
- "Werkstudent" → werkstudent
- "Praktikum" → praktikum
- "Freelance" / "Lehrbeauftragter" → sonstiges
- sonst → festanstellung

**erfahrungslevel:**
- Ausbildungen IMMER "junior"
- Werkstudent/Praktikum meist "junior"
- "Senior X" im Titel oder "8+ Jahre" → senior
- "Junior bis Senior" → egal

**gehalt_min_eur:**
- Range "ab 50.000 €" oder "50.000–60.000 €" → 50000 (Untergrenze)
- "nach Vereinbarung", "attraktive Vergütung", "marktüblich" → null
- Wenn gehalt_min_eur null → gehalt_zeitraum MUSS null sein

**skills_top3:**
- NUR konkrete Tools/Sprachen/Frameworks: Python, SQL, Power BI, AWS, Machine Learning, ETL, ...
- KEINE Soft Skills ("Teamfähigkeit")
- KEINE Sprachen ("Deutsch", "Englisch")
- KEINE Fachgebiete ("Informatik", "BWL")
- Max 3, leeres Array wenn keine technischen Skills genannt
